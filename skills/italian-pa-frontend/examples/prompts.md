# Prompt da usare con Claude Code / Codex

## Generazione

> Usa la skill `italian-pa-frontend` in modalità Generate. Analizza prima lo stack e la versione di Bootstrap Italia installata. Crea un pannello gestione bandi con filtri, tabella e stati vuoto/errore/loading. Non inventare endpoint né dati reali. Fornisci codice, test e punti da verificare manualmente.

## Audit

> Usa `$italian-pa-frontend` in modalità Audit: ispeziona il frontend esistente SENZA modificarlo. Valuta usabilità, accessibilità e coerenza Bootstrap Italia. Produci un report con evidenze file/riga, gravità, verifiche manuali e fix proposti.

## Refactoring

> Applica `italian-pa-frontend` in modalità Refactor solo alla pagina candidature. Preserva endpoint, validazioni, autorizzazioni e comportamento business. Aggiorna UI/UX in accordo col kit installato, aggiungi test e documenta i cambiamenti.

Nota: la sintassi per invocare esplicitamente una skill varia tra strumenti/versioni; è sempre possibile richiamarla per nome nel prompt.
