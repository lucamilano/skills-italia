# Esempi di invocazione indipendenti dallo stack

1. `Usa $italian-pa-frontend. Crea la pagina elenco pratiche con filtri e paginazione usando lo stack già presente nel repository. Non aggiungere framework.`
2. `Usa $italian-pa-frontend. Progetta il flusso di candidatura come specifica UX, senza scrivere codice e senza scegliere una tecnologia.`
3. `Usa $italian-pa-frontend. Crea un form PA con il framework che ti indicherò; se non è chiaro chiedimelo prima di generare file.`
4. `Usa $italian-pa-frontend. Analizza questa UI senza modificarla, applica i contratti di accettazione, distingui problemi accertati da verifiche manuali.`
5. `Usa $italian-pa-frontend. Migliora l'header della mia applicazione Java/Thymeleaf conservando stack, versioni, backend e dipendenze.`
