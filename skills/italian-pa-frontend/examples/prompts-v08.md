# Esempi prompt v0.8

**Wizard indipendente dalla tecnologia**

> Usa $italian-pa-frontend per progettare un wizard di candidatura. Rileva lo stack installato senza sostituirlo. Identifica step, validazioni, focus, errori e riepilogo. Prima di codificare salva una specifica del flusso; non inventare endpoint di salvataggio bozza o invio.

**Form con backend esistente**

> Usa $italian-pa-frontend per migliorare il modulo di presentazione domanda. Mantieni le API esistenti; collega gli errori server-side ai campi, mostra un riepilogo navigabile e verifica gli stati di rete. Documenta ciò che non puoi testare.

**Audit senza modifiche**

> Usa $italian-pa-frontend per analizzare il wizard attuale: validazione, allegati, bozze, invio, accessibilità e comportamento mobile. Restituisci anomalie con prove e suggerimenti, senza modificare il progetto.
