# Code of Conduct

Skills Italia welcomes people of all backgrounds and experience levels. Treat contributors and users with respect in Issues, pull requests, Discussions and other project spaces.

## Expected behavior

Use clear, constructive language. Discuss technical decisions with evidence, acknowledge uncertainty, respect different needs and experience, and give actionable feedback. Accept reasonable corrections. Protect personal information and use synthetic data in examples.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks, impersonation and deliberate disclosure of private information are unacceptable. Repeated disruption, hostile gatekeeping and retaliation against good-faith reports are also unacceptable.

## Reporting and response

Use GitHub's **Report content** menu on the relevant issue, pull request or comment. Choose **Report to repository admins** when that option is available. For harassment, threats or other violations of GitHub's rules, use **Report abuse to GitHub Support**, including the private support form described in [GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Do not publish private incident details in Issues. Reports sent to GitHub Support are handled by GitHub; maintainers may not receive or be able to inspect them. This project uses GitHub reporting channels and publishes no private email address. Security Advisories are reserved for software vulnerabilities, not conduct reports.

Maintainers will assess reports they receive, protect reporter privacy as far as possible, and respond proportionately. Actions may include a warning through an available private channel, removal of content, a temporary participation restriction or a permanent ban. A person involved in a report should not decide their own case; another maintainer should review it when available. Request review of a maintainer decision through the repository's reporting channel when available; decisions made by GitHub follow GitHub's own review process.

This policy governs project participation, not legal adjudication. It is an original project policy licensed under [MIT](LICENSE).
